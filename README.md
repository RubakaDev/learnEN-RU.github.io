# 📘 Linguist AI — Одностраничное веб-приложение для глубокого чтения и разбора английского языка

**Linguist AI** — это персональный интерактивный инструмент для русскоязычных пользователей (уровень Intermediate / Upper-Intermediate), позволяющий читать английские тексты, глубоко понимать логику и восприятие носителей языка (Native Mindset), разбирать грамматические конструкции, накапливать словарный запас и эффективно учить слова по системе интервального повторения Лейтнера.

Приложение полностью автономно, реализовано в **одном файле `index.html`**, не требует сборки, Node.js или бэкенда и запускается в любом современном веб-браузере.

---

## 🛠️ Технологический стек

* **Frontend**: Чистый HTML5, Tailwind CSS (подключение через CDN) и ванильный JavaScript (ES2022+).
* **Сегментация текста**: Встроенный браузерный API `Intl.Segmenter('en', { granularity: 'sentence'|'word' })`.
* **Озвучка**: Встроенный браузерный API `window.SpeechSynthesis` (голос `en-US`).
* **ИИ Провайдеры**:
  * **Google Gemini API** (прямой `fetch` к эндпоинту `v1beta/models/...:generateContent` с заголовком `x-goog-api-key`).
  * **OpenRouter API** (OpenAI-совместимый эндпоинт `chat/completions` для подключения Claude, Llama, DeepSeek, Gemini и др.).
* **Бесплатный переводчик**: Google Translate Web API (`translate.googleapis.com`) — прямые запросы без ключей и без расхода токенов ИИ (0 токенов).
* **Хранение данных**: `localStorage` (все ключи с префиксом `eng_`).

## 🔥 Ключевые возможности и функционал

### 1. 📖 Режим «Чтение» и интерактивный текст
* **Сегментация предложений и слов**: Текст разбивается на предложения и кликабельные слова с помощью `Intl.Segmenter`.
* **Быстрый поповер слова**: Клик по любому слову открывает поповер с транскрипцией (IPA), контекстным переводом, частью речи, кнопкой «+ В словарь» и кнопкой озвучки 🔊.
* **Перевод фраз при выделении**: Выделение мышью любого сочетания слов показывает мини-тултип с кнопками «🔍 Перевести» и «+ В словарь».
* **Подстрочные подсказки (Аннотации)**: Переключатель режима отображения над/под словами (`Ничего`, `Только транскрипция`, `Только перевод`, `Всё`).
* **Синхронизированная подсветка**: Любое слово или многословное выражение из словаря подсвечивается зелёным цветом (`word-in-dict`) в тексте и в карточках разбора, независимо от способа добавления.

---

### 2. ✨ Глубокий разбор предложения носителем языка
Разбор запускается кнопкой **✨** напротив любого предложения и возвращает строго структурированный JSON:
* **Natural vs Literal Translation**: Естественный литературный перевод и буквальный перевод смысловой структуры.
* **Tense Breakdown**: Название грамматического времени, его формула и доступное объяснение причины использования.
* **Grammar Points**: Ключевые акценты (инверсия, пассив, условное наклонение) с точными цитатами и правилами.
* **Native View (Восприятие носителем)**: Интуитивный смысл, стилистический регистр (разговорный, нейтральный, formal), эмоциональная коннотация и нюансы, теряющиеся при переводе на русский.
* **Thinking in English**: 2–3 предложения о том, как мыслить этой фразой на английском, избегая дословного перевода в голове.
* **Vocabulary for Study**: Список ключевых слов и идиом предложения с кнопкой прямого добавления в словарь (`+ В словарь`).
* **Pattern Template**: Скелет/шаблон фразы для повторения вслух и примером аналогичного предложения.
* **Uncertain**: Список неоднозначностей или альтернативных трактовок (если есть).

---

### 3. 📑 «Мои разборы» (История и Избранное)
* Каждый успешный разбор автоматически сохраняется в локальной базе.
* Кнопка **★ «В избранное»** закрепляет важные разборы (автоочистка хранит до 200 неизбранных разборов, а избранные хранятся бессрочно).
* Клик по записи в списке открывает полный разбор мгновенно **без обращения к API**.
* Поиск по тексту предложения, перечислению грамматических правил и фильтрация по временам.

---

### 4. 📚 Словарь и интервальное повторение (Система Лейтнера)
* Карточка каждого слова содержит термин, IPA, часть речи, контекст, категорию, коробку Лейтнера (0–4) и дату следующего повторения.
* **Интервалы Лейтнера**: 0 дней (коробка 0), 1 день (коробка 1), 3 дня (коробка 2), 7 дней (коробка 3), 21 день (коробка 4).
* **Экспорт**:
  * Экспорт словаря в **CSV** (с BOM в кодировке UTF-8 и разделителем `;`).
  * Экспорт в формат **TSV для Anki** (`Front = слово + IPA`, `Back = перевод + контекст`).

---

### 5. 🧠 Режим обучения «Учить» (Карточки и Тесты)
* **3D-карточки повторения**: Переворот карточки по клику или клавише `Пробел` / `Enter`. При показе и перевороте карточки автоматически срабатывает озвучка слова.
* **4 варианта оценки Лейтнера**: `[1] Не знаю`, `[2] Трудно`, `[3] Хорошо`, `[4] Легко`.
* **Интерактивные тесты**:
  1. `🇬🇧→🇷🇺` — Выбор правильного перевода из 4 вариантов.
  2. `🇷🇺→🇬🇧` — Выбор английского слова из 4 вариантов.
  3. `⌨️ Ввод перевода` — Ручной ввод английского слова с клавиатуры с автоматической проверкой.

---

### 6. 📁 Менеджер текстов и изоляция данных
* Возможность создавать, хранить и переключаться между несколькими учебными материалами.
* **Изолированный контекст**: При смене материала подгружаются именно его словарь, сохранённые разборы предложений, очередь повторения карточек и заметки. Данные разных материалов не перемешиваются.

---

### 7. 📝 Блокнот для заметок
* Компактная область заметок (`#section-notepad`) в нижней части приложения.
* Позволяет сохранять пользовательские заметки, правила и мысли в привязке к текущему учебному материалу с автосохранением.

---

### 8. ☀️ / 🌙 Темизация оформления
* Мгновенный переключатель между **Тёмной** (Notion / Linear style) и **Светлой** темами с сохранением выбора пользователя.

---

### 9. 🌐 Кастомные Прокси и API ИИ
* В настройках (⚙️) можно задать:
  * **Google Gemini API Key** и **Google Model** (по умолчанию `gemini-2.5-flash`).
  * **OpenRouter API Key** и **OpenRouter Model** (например, `anthropic/claude-3.5-sonnet`, `deepseek/deepseek-r1` и др.).
  * **Custom Base URL / Proxy** для кастомного проксирования ИИ-трафика при необходимости.
  * **Google Translate** работает напрямую (без прокси и без API-ключей).

## 💾 Структура хранения (localStorage)

Все ключи хранятся в `localStorage` браузера с префиксом `eng_`:

* `eng_settings`: Объект настроек (провайдер, API-ключи, прокси-URL, модели, тема, режим подсказок).
* `eng_texts_v2`: Массив всех созданных учебных материалов `{ id, title, content, dictionary, analyses, notes, createdAt }`.
* `eng_active_text_id`: ID текущего выбранного материала.
* `eng_cache`: Кэш ответов Gemini / OpenRouter (по хешу предложений и слов).
* **Бэкап JSON**: Кнопка «Экспорт бэкапа» сохраняет весь словарь, разборы, тексты и заметки в JSON (API-ключи из бэкапа исключаются в целях безопасности).

## 🚀 Как запустить

1. Скачайте файл `index.html`.
2. Откройте его в любом современном браузере (Chrome, Edge, Firefox, Safari).
3. Нажмите на шестерёнку **⚙️** в правом верхнем углу и укажите ваш **Gemini API Key** (из [Google AI Studio](https://aistudio.google.com/app/apikey)) или **OpenRouter API Key**.
4. Вставьте английский текст и наслаждайтесь чтением с глубоким разбором!
